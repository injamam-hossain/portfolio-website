INJAMAM HOSSAIN — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It opens in your browser.

HOW TO CUSTOMIZE BEFORE PUBLISHING
- In index.html, replace YOUR_EMAIL@example.com with your real email address.
- Check the Fiverr profile link and update it if your seller profile URL changes.
- The portfolio samples are clearly labelled as self-initiated practice concepts. Keep that wording honest.
- You can edit text in index.html and colors/layout in style.css.

FILES
- index.html: website content
- style.css: responsive design and styling
- script.js: mobile navigation and current year

This is a static website. It does not require a server or paid hosting to preview.
